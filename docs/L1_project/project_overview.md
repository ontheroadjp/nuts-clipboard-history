# プロジェクト概要

Nuts Clipboard History は GNOME Shell 50 上でコピーしたテキストを保存し、検索画面から貼り付ける拡張です（`README.md:1-9`, `nuts-clipboard-history@local/metadata.json:1-8`）。GJS と GNOME Shell の API を利用し、履歴の単体検証には Node.js を使います（`nuts-clipboard-history@local/extension.js:1-9`, `package.json:1`）。外部パッケージ依存は package.json に定義されていません。
